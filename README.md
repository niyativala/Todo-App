# 📝 ToDo App

A simple and interactive ToDo Application built using HTML, CSS, and JavaScript.

This project helps users manage daily tasks efficiently with features like adding, viewing, updating, deleting tasks, and switching between light and dark themes.

---

## 🚀 Features

* ➕ Add new tasks
* 📋 Display all tasks
* ✏️ Update existing tasks
* 🗑️ Delete tasks
* 🌙 Dark Mode Toggle
* ⚡ Dynamic DOM Manipulation
* 📱 Responsive User Interface

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

---

## 📂 Project Structure

* index.html → App structure and UI
* style.css → Styling and layout
* script.js → Task management logic  

---

## ⚙️ How It Works

1. Enter a task in the input field.
2. Click Add Task to save the task.
3. Click Show Task to display all tasks.
4. Click Update Task to modify an existing task.
5. Click Delete Task to remove the latest task.
6. Use Toggle Theme to switch between Light and Dark Mode.

---

## ▶️ How to Run Project

1. Clone the repository:
git clone https://github.com/niyativala/Todo-App.git
2. Open the project folder.
cd Todo-App
3. Open index.html in your browser.

---

### 📊 Project Logic (Simple)

* User enters a task in the input field.
* Task is stored in a JavaScript array when Add Task is clicked.
* Show Task displays all tasks dynamically using DOM Manipulation.
* Update Task modifies an existing task.
* Delete Task removes a task from the list.
* Toggle Theme switches between Light and Dark Mode using classList.toggle().
